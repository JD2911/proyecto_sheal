# SHEAL Travel Agency

Página web estática creada con HTML5, CSS3 y JavaScript vanilla.

## Archivos

- index.html
- style.css
- script.js
- assets/

## Cómo ejecutarla

1. Abre la carpeta `sheal-travel`.
2. Abre `index.html` en el navegador.

También puedes subir toda la carpeta a Netlify.

## Importante

Las fotografías están conectadas mediante URLs de imágenes públicas para que el diseño funcione inmediatamente.

Cuando tengas las imágenes definitivas de SHEAL, puedes guardarlas dentro de `assets/` y reemplazar las URLs de imágenes en `index.html` y `style.css`.
